# macOS arm64 编译告警修复测试计划

本文档约束 `macos-arm64-build-report-2026-07-15.md` 所列问题的实施顺序。每一项必须先补充聚焦测试，确认测试能够覆盖原缺陷，再修改生产代码；聚焦测试和相关回归全部通过后，才允许使用中文提交信息提交并进入下一项。

## 1. HisDataReplayer L2 游标与事件归并

修复前测试：

- 空列表、单条列表、最后一条及完全耗尽后的下一时间查询。
- 从区间起点初始化游标，覆盖起点之前、恰好等于起点和起点之后的数据。
- 没有 tick、只有委托明细/逐笔成交/委托队列时仍能完成区间回放。
- 同一时间戳按“委托明细、逐笔成交、tick、委托队列”顺序触发。
- 一类 L2 数据加载失败时，不得清空其他类型的有效缓存。
- tick 位于非交易时段、收盘后以及流已耗尽时不得越界。

修复后验收：聚焦 GTest、`WonderTrader.TestUnits`、WtBtCore 构建通过；后续具备行情样本时补充按日和分钟区间端到端回放。

## 2. HFT 未完成量与撤单

修复前测试：买单、卖单、零剩余、部分成交、多订单净额；卖单恢复时撤单数量必须使用绝对值；并发查询和撤单使用订单快照。

修复后验收：HftMocker 聚焦测试、HFT demo 编译、WtBtCore 和相关 C 接口构建通过。

## 3. UFT 未完成量与一键撤单

本轮以现有实盘行为为兼容基准：返回所有活动订单剩余量的绝对和。测试覆盖开多、开空、平多、平空、部分成交、多订单，以及 `stra_cancel_all` 返回所有已提交撤单的本地 ID。若未来改为“买正卖负”，须同步修改实盘和回测并提供新契约测试。

## 4. TPT_None 一次性调度

测试覆盖指定日期/时间只触发一次、日期不匹配、严格时间、错过时间、节假日和实盘/回测判定一致；无效 period 必须显式拒绝或记录错误，不能静默变成一次性任务。

## 5. ExpCtaMocker notifier 参数

测试覆盖配置路径仍启用持久化、notifier 非空、会话结束发送 `BT_FUND`，并保证现有 CTA 30m 回归结果不变。

## 6. IDataWriter 插件生命周期

测试插件必须通过 `createWriter/deleteWriter` 创建和销毁派生对象，并记录派生析构函数副作用；ASan/UBSan 不得报告错误。修复前后公共头布局、导出符号和工厂函数签名保持不变。

## 7. OrderInfo 生命周期与输入边界

测试覆盖默认值、不可复制约束、最大合法代码和 user tag、超长输入拒绝，以及正常下单/撤单/成交路径。

## 8. WTSVariant 与配置 null

整数转换覆盖所有整数类型的最小值和最大值及精确十进制文本。JSON/YAML null 在本轮保持现有“忽略字段/元素”行为，并用显式测试固化。

## 9. StackTracer 与 SignalHook

StackTracer 测试覆盖空符号列表、解析失败、demangle 失败和长符号；SignalHook 使用子进程验证 SIGINT/SIGTERM 的正常退出与致命信号路径，handler 内不得调用非异步信号安全操作。

## 10. 合约 ID

测试覆盖各字段最大合法长度、组合后的完整 ID 最大长度、超长字段拒绝、组合超长拒绝和 map key 不发生静默截断碰撞；公共对象布局不得变化。

## 11. IniHelper

测试覆盖长 section/key、空 section/key、原有文件读写文本、多个实例并发路径构造；不宣称同一实例并发写安全。

## 12. TimeUtils

测试覆盖带/不带毫秒的精确格式、负时间、时区行为、自定义 `strftime` 格式接近缓冲区上限，以及多线程调用 `Time32::fmt` 不互相覆盖。

## 13. LMDB section

运行现有 LMDB 写入、只读、范围查询和重开测试；macOS 使用 `otool -l` 检查异常 section 消失，并重建所有链接 WTSUtils 的目标和安装 smoke。

## 14. override 与构建告警策略

`override` 修改逐模块构建。warning target 先对已清零的自有目标启用，第三方源码不得继承 `-Werror`；CI 对规范化唯一诊断做预算测试，并验证 C++17/20、Debug/Release 和 macOS arm64 presets。
